# 🍔 Food Junction — Django Full-Stack Food Ordering Website

A modern, responsive food ordering website developed as a **business demo for a local food business**.

The project converts a food business website into a full-stack Django application where menu items, prices, availability, offers, food images, and customer orders can be managed through the Django Admin.

---

## 📌 About the Project

Food Junction was developed to demonstrate how a local food business can have a professional online presence with a digital menu and ordering system.

The website provides customers with an easy way to:

- Browse food categories and menu items
- View food details and prices
- Add multiple items to a cart
- Use the Buy Now option
- Apply promotional codes
- Place orders through checkout
- Select a payment method
- Receive an order confirmation

The business owner can manage the website through the Django Admin without directly modifying the source code.

> **Project Type:** Business Demo / Portfolio Project  
> **Target Business:** Local Food Business

## ✨ Features

### 👤 Customer Features

- 🍔 Dynamic food menu
- 📂 Food categories
- 🔎 Food details and descriptions
- 💰 Dynamic prices
- 🛒 Shopping cart
- ➕ Increase/decrease item quantity
- 🗑️ Remove items from cart
- ⚡ Buy Now option
- 🎟️ Promotional codes
- 📦 Checkout and order placement
- 💳 COD / Online payment method selection
- 🧾 Order confirmation with order ID
- 📱 Responsive design for desktop, tablet and mobile

### 👨‍💼 Admin Features

The Django Admin allows the business owner to manage:

- Food items
- Food categories
- Prices
- Food availability
- Veg / Non-veg information
- Food tags such as Bestseller, Spicy and New
- Food images
- Pizza sizes and prices
- Promotional offers
- Customer orders
- Order status

Orders can be updated through statuses such as:

**Pending → Confirmed → Preparing → Out for Delivery → Delivered / Cancelled**

## 🗄️ Backend & Database

This project uses **Django as the backend framework** and **SQLite as the database**.

The application stores and manages:

- Food categories
- Food items
- Food sizes
- Food images
- Promotional offers
- Customer orders
- Order items
- Payment method information

When a customer places an order, the order and its items are stored in the database and can be viewed through the Django Admin.
